# Sudoku Web Application

Веб-приложение классической головоломки «Судоку», реализованное на чистом стеке HTML5, CSS3 и Vanilla JavaScript. Интерфейс выполнен в минималистичной темной теме без сторонних библиотек и внешних зависимостей.

---

## 📌 Основные возможности

* **Генерация уникальных полей**:
  * Создание валидной базовой сетки 9×9 через матричные сдвиги.
  * Рандомизация с сохранением правил игры: обмен строк и столбцов внутри районов 3×3, обмен целых блоков (районов), подстановка чисел и транспонирование матрицы.
* **3 уровня сложности**:
  * `Легкий` — 32 пустые ячейки.
  * `Средний` — 44 пустые ячейки.
  * `Сложный` — 54 пустые ячейки.
* **Игровая статистика и таймер**:
  * Посекундный учет времени партии.
  * Подсчет количества допущенных ошибок с кратковременной визуальной индикацией.
* **Вспомогательные инструменты**:
  * **Проверить**: подсвечивает корректные ходы и ошибочно заполненные ячейки.
  * **Подсказка**: автоматически открывает правильное число в выбранной некорректной или случайной свободной ячейке.
  * **Защита исходных данных**: начальные цифры заблокированы от случайного изменения или стирания.
* **Сохранение рекордов**:
  * Фиксация наилучшего времени для каждой сложности в `localStorage` браузера.
  * Возможность сброса локальной таблицы рекордов.
* **Управление**:
  * Мышь / тач-ввод.
  * Экранная цифровая клавиатура (1–9, «Стереть»).
  * Физическая клавиатура: цифры `1`–`9`, `Backspace` / `Delete` / `0` для удаления, стрелки навигации `↑`, `↓`, `←`, `→`.

## 🖥 Архитектура интерфейса

Приложение разделено на три функциональные зоны:

| Секция | Содержимое |
| :--- | :--- |
| **Левая панель** | Заголовок, статус партии, выбор сложности, таймер, счетчик ошибок. |
| **Центр** | Игровое поле 9×9 с визуальным выделением строк, столбцов, районов и одинаковых цифр. |
| **Правая панель** | Экранный цифровой блок ввода, кнопки действий («Новая игра», «Проверить», «Подсказка») и таблица лучших результатов. |

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone [https://github.com/whoami-28/sudoku.git](https://github.com/whoami-28/sudoku.git)
cd sudoku

```


2. Запустите проект:
* **Локально**: откройте файл `index.html` в любом современном браузере.
* **Через локальный сервер** (например, с помощью Python):
```bash
# Python 3
python -m http.server 8000

```


После запуска перейдите по адресу: `http://localhost:8000`.

## 🛠 Стек технологий

* **HTML5**: семантическая разметка (`<main>`, `<aside>`, `<header>`).

* **JavaScript (ES6+)**: чистый JavaScript без фреймворков, DOM API, Web Storage API (`localStorage`).
